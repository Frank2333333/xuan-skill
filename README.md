# xuan Skill

基于 Claude Code / Codex 的八字命理画像与生涯复盘工具。主路径是用户直接给出四柱八字和性别，Skill 会用铁口直断式断语把命局结构转化为证据链清晰的人物画像；若补充出生年份、出生日期或起运信息，则按大运流年从出生推演到今天，复盘事业状态、感情经历、身体健康、迁移变化等关键事件及其影响。家庭事实不再从八字默认推断，只能以用户提供的现实信息为准。

## 产品主轴

这个 Skill 的核心不是“多说”，而是同时做到两件事：

1. **帮用户更深入地了解自己**
   不只判断吉凶，还要把命局结构转成性格底色、行为模式、关系模式、压力来源、优势短板和人生主线，让用户理解“为什么自己会这样”。
2. **帮用户拿到关心问题的答案和精准建议**
   用户问事业、财运、婚姻、健康、流年、阶段变化时，先直接回答问题；当用户明确需要建议时，再给聚焦当前问题、当前阶段的精准建议。

## 默认体验流程

为了把用户体验做稳，这个 Skill 默认按两步走：

1. **先交付命主分析报告**
   当用户已经提供`性别 + 八字四柱`，或补足出生信息后已能排出四柱，但还没有限定单一问题时，Skill 默认先输出一份结构化`命主分析报告`，把命局结构、核心画像、现实抓手、当前阶段和校准点先说明白。
2. **再承接按月建议**
   用户后续继续追问`本月 / 下个月 / 按月 / 月度建议 / 月度提醒`时，Skill 默认基于前面的命主报告进入`月度建议模式`，先锚定绝对月份或节气区间，再给当月主题、现实表现、风险点和 1-3 条精准建议。

这两步的目标是：
- 先让用户对自己有系统理解，而不是只拿到零散结论。
- 再让用户在具体月份里拿到短、准、能执行的提醒，而不是每次都重做整份画像。

对应的输出原则：

- 先回答用户最关心的问题，再展开命局解释。
- 先给结论，再给证据链和现实落点。
- 建议必须少而准，直接服务于用户当前问题；不为了显得全面而稀释重点。

## 功能

- **八字画像** — 通过四柱八字和性别，输出性格底色、行为模式、事业能力、关系模式、健康风险提示和成长建议
- **命主分析报告** — 在用户提供性别和八字后，默认生成结构化首轮报告，作为后续年度、月度、专题追问的统一底稿
- **铁口直断** — 回答第一行先下断语，再给依据和校准点；禁止用八字直接断“富贵之家”“家底厚”“父辈有财”等家庭事实
- **现实语境定位** — 只根据用户已提供的职业、经营、资产、城市、现金流压力和当前问题定位语境，不反推家庭背景
- **命局计算** — 解析年柱、月柱、日柱、时柱，计算日主、十神、藏干、五行强弱、刑冲合害、格局和喜忌
- **生涯复盘** — 按大运流年从出生推演到今天，列出关键年份、事件领域、触发机制、影响和置信度
- **当前问题定位** — 把用户现阶段的问题放回命局、大运、流年和历史经历中，寻找惯性反应与破局点
- **名家断法借鉴** — 回答具体问题时系统借鉴徐子平、沈孝瞻、张楠、任铁樵、韦千里、袁树珊、徐乐吾等历史命理人物的方法
- **财富与资源分析** — 只分析用户本人收入能力、经营模式、现金流压力、风险偏好和资产动作；家庭财富须由用户提供事实后再解释
- **排盘补充** — 用户只给阳历/农历生日、出生时间和性别时，可先排出四柱，再进入画像分析
- **校准反馈** — 给出可验证的现实校准点，根据用户反馈修正格局、用神和画像判断
- **月度建议** — 在已有命主报告的前提下，按绝对月份/节气区间输出当月主题、现实表现、风险点和短促精准的建议

## 安装

> **注意**：Claude Code 从 git 仓库根目录的 `.claude/skills/` 查找 skill，请在正确的位置执行。

```bash
# 安装到当前项目（在 git 仓库根目录执行）
mkdir -p .claude/skills
git clone https://github.com/Frank2333333/xuan-skill .claude/skills/xuan

# 或安装到全局（所有项目都能用）
git clone https://github.com/Frank2333333/xuan-skill ~/.claude/skills/xuan
```

## 使用

在 Claude Code 中输入以下任意关键词即可触发：

安装后的技能名为 `xuan`，同时保留 `bazi` 作为关键词别名。

`xuan` `算八字` `看八字` `批八字` `八字画像` `精确画像` `命理画像` `性格画像` `人生复盘` `生涯推演` `历史事件` `名家断法` `铁口直断` `四柱` `命盘` `算命` `排盘` `bazi`

推荐直接提供四柱八字和性别：

```text
甲子年 丙寅月 戊午日 癸亥时，男
```

如果需要从出生推演到今天，建议同时提供出生年份或出生日期、起运年龄，以及当前想解决的问题：

```text
甲子年 丙寅月 戊午日 癸亥时，男，1990年生，想看事业和感情为什么反复卡住
```

触发后，Skill 会校验八字，解析命局结构，输出结构化人物画像，并在信息足够时按大运流年复盘关键事件。若只提供出生信息，Skill 会先排盘，再进入同样的画像与生涯复盘流程。

推荐的连续使用方式：

```text
第一轮：给出性别 + 八字，请做一份命主分析报告
第二轮：继续按 2026 年 4 月给我一份月度建议
```
